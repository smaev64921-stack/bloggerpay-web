# UI-анимация: движение как ориентир

## Главный принцип

Анимация отвечает пользователю на один из трёх вопросов:
**откуда это появилось**, **куда это делось**, **что сейчас происходит**.
Если ответа нет — это украшение, и его место под сомнением.

## Нормы длительности

| Что | Сколько |
|---|---|
| Микрореакция (кнопка, чекбокс) | 80–150 мс |
| Появление элемента, тултип | 200 мс |
| Переход экрана, шторка | 250–300 мс |
| Крупная модалка на весь экран | 300–350 мс |
| Что-либо дольше 400 мс | почти всегда ошибка |

Асимметрия: открытие плавное и заметное, закрытие быстрее на треть —
пользователь уже принял решение уйти, не задерживайте его.

## Технические границы

- Анимировать **только `transform` и `opacity`** — остальное дёргает
  раскладку и роняет кадры на слабых телефонах.
- Направление осмысленно: шторка снизу — уезжает вниз; появившееся
  справа — уходит вправо. Возврат = обратная дорога.
- Начальное состояние задавать явно (`fill-mode: backwards` или класс),
  иначе элемент мелькает готовым до старта анимации.
- Одновременно двигаются не больше двух-трёх групп элементов.

## Состояния, о которых забывают

- **Ожидание**: после 300 мс тишины — спиннер или скелетон; мгновенные
  спиннеры на быстрых операциях сами создают ощущение медленности.
- **Пустой экран**: появляется с тем же переходом, что и контент.
- **Ошибка**: привлекает внимание один раз (дрожь, цвет) и замолкает,
  а не пульсирует бесконечно.

## Доступность — не по желанию

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
}
```

Смысловые изменения (появление/скрытие) обязаны работать и без анимации:
движение — украшение состояния, а не его носитель.

## Аудит существующего интерфейса

Пройти по экранам и спросить у каждой анимации:
1. Длительность в норме из таблицы?
2. Свойства только transform/opacity?
3. Первый показ без мигания? Возврат на экран без повторного «салюта»?
4. Reduced motion выключает её?
Всё, что не прошло, — чинить или удалять.
