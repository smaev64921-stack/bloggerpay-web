# Дизайнер анимаций: движение, которое выглядит дорого

## Порядок работы

1. Назвать **цель** движения: показать связь, направить взгляд, скрыть ожидание.
   Движение без цели — вырезать.
2. Выбрать **иерархию**: главный элемент двигается заметно, второстепенные —
   тише и с задержкой. Всё сразу и одинаково = дёшево.
3. Собрать на токенах длительности/кривых, не на волшебных числах.

## Переходы страниц

- Уходящая страница: короче и тише (150 мс, лёгкий сдвиг + затухание).
- Входящая: 250–300 мс, сдвиг 12–24px по направлению навигации
  (вперёд — справа, назад — слева). Осязаемое ощущение «куда я иду».
- Общий элемент двух экранов (карточка → её детальный вид) — переезжает,
  а не исчезает: View Transitions API либо FLIP-техника
  (First-Last-Invert-Play: замерить, применить обратный transform, отпустить).

## Каскадные списки

Появление списка — волной сверху вниз, шаг 30–50 мс, не больше 8–10 позиций
(дальше задержку обнулять — никто не ждёт 20-й элемент):
`delay = min(i, 8) * 40ms`. Обязательно `fill-mode: backwards`.

## Параллакс и прокрутка

- Слои двигаются с разной скоростью: фон 0.2–0.4 от скорости прокрутки.
  Реализация — `animation-timeline: scroll()` где доступно, иначе
  rAF + `transform` (никогда не `background-position` на каждый скролл).
- Индикатор прочитанного: тонкая полоса, `scaleX` от прогресса.
- Появление секций по мере прокрутки: `IntersectionObserver`, порог 0.15,
  анимация один раз (`unobserve` после срабатывания).

## Микровзаимодействия

- Кнопка: нажатие — `scale(0.97)` за 80 мс; отпускание — назад с `--e-out`.
  Успех — короткая вспышка/галочка 400 мс, не конфетти на полэкрана.
- Поля: ошибка — горизонтальная дрожь 3 колебания по 4px, 250 мс всего.
- Скелетоны: волна блика слева направо 1.2 с, `linear`, бесконечно;
  замена контентом — перекрёстное затухание, не прыжок.
- Переключатели/вкладки: подчёркивание-плашка едет за активной вкладкой
  (FLIP или `transform` по замеру), 200 мс.

## Критерии готовности

- 60 fps на среднем телефоне (проверить с 4× CPU throttling).
- Ничего не мигает при первом показе и при возврате на экран.
- `prefers-reduced-motion` переводит всё в мгновенные переходы.
- Движение можно объяснить одной фразой «оно показывает, что…».
