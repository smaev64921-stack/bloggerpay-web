# BloggerPay

Биржа рекламы у блогеров: рекламодатель находит блогера, деньги
замораживаются на счёте сделки и уходят исполнителю после выполнения
работы. Комиссия со сделки — 0%, сервис зарабатывает 4% при выводе.

Работает как мини-приложение Telegram и как обычный сайт.

## Что в репозитории

| Файл / папка | Что это |
|---|---|
| `bloggerpay-1008-v100.html` | само приложение — один файл, без сборки |
| `onboarding.html` | знакомство при первом входе, 4 экрана |
| `privacy.html` | политика конфиденциальности (нужна для проверки Google и TikTok) |
| `sw.js` | офлайн-режим |
| `netlify.toml` | заголовки для хостинга |
| `server/` | сервер-касса: деньги, выплаты, проверка личности, бот |

Инструкции: **`ВЫКЛАДКА.md`** (как поднять), `ПОДКЛЮЧЕНИЕ-СОЦСЕТЕЙ.md`
(ключи TikTok и YouTube), `ЧТО-ГДЕ.md` (карта проекта).

## Запуск бота на хостинге

Это то, что нужно для работы сервиса: бот присылает человеку кнопку
«🚀 Открыть BloggerPay», она открывает приложение как мини-апп Telegram.

**Команда запуска:**

```bash
npm start
```

(то же самое, что `node server/bot.js`)

**Две переменные окружения** — задаются в панели хостинга:

| Переменная | Где взять |
|---|---|
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/mybots` → ваш бот → API Token |
| `APP_URL` | адрес сайта с приложением по `https`, например `https://ваш-сайт.netlify.app` |

Больше боту ничего не нужно: ни базы, ни домена, ни открытого порта. Он сам
ходит в Telegram за сообщениями (длинный опрос), поэтому снаружи его никто
не должен видеть.

Если с сервера не открывается `api.telegram.org` — так бывает у хостингов в
России — пропишите `TG_API_BASE` с адресом своего прокси, который передаёт
запросы в Telegram один в один.

**Касса — отдельно и не обязательна.** Приложение открывается и работает без
неё, только деньги живут в браузере человека. Она нужна, когда деньги должны
стать настоящими (эскроу, выплаты, восстановление пароля письмом):

```bash
npm run cashier
```

Это **второй процесс**, не замена первому. Ему нужны Node 22.5+ и свои
настройки — см. `server/.env.example` и `ВЫКЛАДКА.md`.

## Быстрый старт

Приложение — статический файл, его достаточно открыть или положить на любой
хостинг. Без сервера оно работает в тестовом режиме: данные живут в браузере.

Сервер (нужен Node 22.5+, зависимостей нет):

```bash
cd server
cp .env.example .env      # заполнить ADMIN_KEY и остальное
node server.js            # касса на порту 8090
node bot.js               # телеграм-бот с кнопкой «Открыть»
```

Рабочее место оператора — `/operator` на адресе сервера: выплаты,
проверка личности, спорные деньги, поломки.

## Проверки

```bash
cd server
node test-scenario.mjs    # сделка, вывод, дыры из аудита
node test-partial.mjs     # бюджет кампании на нескольких блогеров
node test-disputes.mjs    # раздел спорных денег арбитром
node test-kyc.mjs         # проверка личности оператором
node test-pay.mjs         # режимы кассы и предохранители пополнения
node test-verify.mjs      # подтверждение каналов TikTok/YouTube
node test-bot.mjs         # разговор бота (на заглушке, без Телеграма)
```

Всего 152 проверки.

## Как устроены деньги

1. **Баланс не хранится** — он считается как сумма журнала операций.
   Расхождение невозможно по построению.
2. **Журнал только растёт.** Отмена — это встречная запись, а не правка.
3. **Одна операция проводится один раз** — у каждого денежного запроса есть
   ключ идемпотентности.

Сверка видна оператору: внесено − выплачено = столько-то в системе. Если
равенство разошлось, полоса краснеет.

## Безопасность

**`server/.env` не входит в репозиторий** — там ключ оператора, токен бота
и ключи платёжной кассы. Если такой файл случайно попал в публичный
репозиторий, удалить коммит недостаточно: ключи нужно перевыпустить.
